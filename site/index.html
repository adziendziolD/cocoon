CoCoon runs Claude Code, Codex and other coding agents in isolated sandboxes on your own server – and gives you one place to plan their work, watch them live and decide what makes it into your code. CoCoon lässt Claude Code, Codex und andere Coding-Agenten in isolierten Sandboxes auf deinem eigenen Server arbeiten – und gibt dir einen Ort, an dem du ihre Arbeit planst, sie live beobachtest und entscheidest, was in deinen Code kommt.

SecuritySicherheit

Isolated by defaultStandardmäßig isoliert

Each sandbox is a hardened container (or a bubblewrap process sandbox). Internet access is restricted to an allowlist, and API keys never enter the sandbox.Jede Sandbox ist ein gehärteter Container (oder eine bubblewrap-Prozess-Sandbox). Internetzugang nur über eine Freigabeliste, und API-Keys kommen nie in die Sandbox.

  • Egress proxy: blocked connections are logged and can be allowed with one clickEgress-Proxy: blockierte Verbindungen werden protokolliert und lassen sich mit einem Klick erlauben
  • Credential proxy: agents only see placeholders, the real key is added on the way outCredential-Proxy: Agenten sehen nur Platzhalter, der echte Key kommt erst auf dem Weg nach draußen dazu
  • Non-root, no capabilities, CPU/RAM/PID limits, optional gVisor or KataKein Root, keine Capabilities, CPU-/RAM-/PID-Limits, optional gVisor oder Kata

Updates at the push of a buttonUpdates auf Knopfdruck

CoCoon checks daily whether it, the agent CLIs and its images are up to date – and updates itself with git + pnpm, rolls back on failure and restarts.CoCoon prüft täglich, ob es selbst, die Agent-CLIs und seine Images aktuell sind – und aktualisiert sich per git + pnpm, rollt bei Fehlern zurück und startet neu.

Quickstart

Running in a few minutesIn wenigen Minuten startklar

You need Node.js 24, pnpm and Docker, Podman or – on Linux – bubblewrap.Du brauchst Node.js 24, pnpm und Docker, Podman oder – unter Linux – bubblewrap.

  1. Clone and set up – installs dependencies and builds the web UI.Klonen und einrichten – installiert Abhängigkeiten und baut die Oberfläche.
  2. Start – the console prints a login link.Starten – die Konsole zeigt einen Login-Link.
  3. Follow the wizard – it prepares the sandbox image, the proxy and the agent tools for you.Dem Assistenten folgen – er bereitet Sandbox-Image, Proxy und Agent-Werkzeuge für dich vor.

Read the full documentationZur vollständigen Dokumentation →

$ git clone https://github.com/adziendziolD/cocoon.git
$ cd cocoon
$ pnpm setup
$ pnpm start

  CoCoon is running: http://127.0.0.1:7420
  Sandbox backend: docker
  Log in: http://127.0.0.1:7420/?token=cct_…

# from another terminal, or from a script
$ pnpm cocoon sandbox create --name demo \
    --repo https://github.com/you/repo.git
$ pnpm cocoon agent spawn <sandbox-id> claude-code \
    -p "Fix the failing tests"
